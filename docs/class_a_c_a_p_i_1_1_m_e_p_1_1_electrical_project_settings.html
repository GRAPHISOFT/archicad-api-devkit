Detailed Description

ElectricalProjectSettings holds the project-level electrical configuration: load classification descriptions, wiring type descriptions, and default voltage.

This object is a singleton per project. Use GetElectricalProjectSettings to retrieve it. It provides read access to the defined load classifications and wiring types, which are referenced by ElectricalDevice and ElectricalCircuit respectively.
