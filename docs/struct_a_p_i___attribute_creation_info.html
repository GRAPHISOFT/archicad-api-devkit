Detailed Description

Creation metadata attached to an attribute.

Since
Archicad 30
Remarks
Provides information about how and by whom an attribute was created. These values are populated by the host when the attribute is inserted into the set and can be queried via helper functions (e.g., Attribute_GetCreationInfo). Not all fields may be available for legacy or imported attributes.
