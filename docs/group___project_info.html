GSErrCode ACAPI_ProjectInfo_CreateField ( const API_Guid & groupGuid,
const GS::UniString & name,
API_Guid & createdFieldGuid )

Creates a new custom ProjectInfo field in the specified group.

Since
Archicad 30
Parameters
groupGuid[in] The GUID of the group to create the field in.
name[in] The name for the new field.
createdFieldGuid[out] The GUID of the created field.
Returns
  • NoError - The function has completed with success.
  • APIERR_BADID - The given group GUID does not exist.
  • APIERR_NAMEALREADYUSED - A field with the given name already exists.
  • APIERR_NOACCESSRIGHT - The user does not have the Teamwork permission to modify Project Info.
Example
GSErrCode CreateCustomField (const API_Guid& groupGuid)
{
API_Guid createdFieldGuid;
GSErrCode err = ACAPI_ProjectInfo_CreateField (groupGuid, "My Custom Field", createdFieldGuid);
if (err == NoError) {
err = ACAPI_ProjectInfo_SetFieldValue (createdFieldGuid, "Initial Value");
}
return err;
}

◆ ACAPI_ProjectInfo_GetFields()

GSErrCode ACAPI_ProjectInfo_GetFields ( const API_Guid & groupGuid,
std::vector< API_Guid > & fieldGuids )

Retrieves the GUIDs of all fields in a ProjectInfo group, including subfields.

Since
Archicad 30
Parameters
groupGuid[in] The GUID of the group.
fieldGuids[out] Array to be filled with the GUIDs of all fields in the group (including subfields), in order.
Returns
  • NoError - The function has completed with success.
  • APIERR_BADID - The given group GUID does not exist.
Remarks
Subfields of fields are also returned. Subfields are fields whose values contribute to a parent field's calculated value (e.g., address components of a full address field).
Example
GSErrCode ListFieldsInGroup (const API_Guid& groupGuid)
{
std::vector<API_Guid> fieldGuids;
GSErrCode err = ACAPI_ProjectInfo_GetFields (groupGuid, fieldGuids);
if (err == NoError) {
for (const API_Guid& fieldGuid : fieldGuids) {
GS::UniString name, value;
if (ACAPI_ProjectInfo_GetField (fieldGuid, name, value) == NoError) {
ACAPI_WriteReport (" %s = %s", false, name.ToCStr ().Get (), value.ToCStr ().Get ());
}
}
}
return err;
}
